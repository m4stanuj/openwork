# M4ST MCP Workspace Public Copy

M4ST MCP Workspace is the portable workspace/control-plane layer by Mast Anuj.

It keeps AI coding assistants aligned through shared MCP configuration, reusable skills, local setup checks, and safe workflow boundaries.

## Public Description

M4ST MCP Workspace provides:

- portable MCP setup
- reusable skills
- project context conventions
- setup diagnostics
- browser/file automation boundaries
- integration patterns for M4ST workflows

## Safety Boundary

Use it only for authorized, defensive, and user-approved automation.

Pause for human handoff on OTP, CAPTCHA, payment, legal approval, public posting, account recovery, or irreversible actions.
